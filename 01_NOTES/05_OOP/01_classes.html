🐍 Lesson 4: Object-Oriented Python (Classes & Node References)

Bhai, aaj hum Object-Oriented Programming (OOP) ke basic nodes seekhenge. Ye concept sabse important hai agar hume custom structures jaise Linked List, Stacks, Queues, aur Trees banane hain.

1️⃣ Concept: Class, Objects, and Node Reference

🟢 YE KYA HAI? (Definition)
Class ek blueprint (naksha) hoti hai, aur Object us blueprint se bana actual block/instance hota hai. Python me node structures banane ke liye hum custom classes ka use karte hain.

🖼️ DIAGRAM: Linked Node References in Memory

node1 (Node Object) node2 (Node Object) +---------------+ +---------------+ | val | next |----------------->| val | next |-----> None | 10 | | | 20 | None | +---------------+ +---------------+
🟢 WHY USE IT?
Linked structures me elements memory me contiguous nahi hote. Isiliye hum ek element se dusre element tak pohochne ke liye Node references (pointers) ka use karte hain.

2️⃣ Code Implementation

# 1. Custom Class structure
class Node:
    # Constructor: Python me __init__ use hota hai (dunder init)
    # self represents the current object (JS 'this' equivalent)
    def __init__(self, val):
        self.val = val      # Value store karne ke liye
        self.next = None    # Initial pointer is None

# 2. Objects initiation
node1 = Node(10)
node2 = Node(20)

# 3. Linking nodes
node1.next = node2  # node1 points to node2

3️⃣ Avoid Common Pitfalls

🔴 COMMON MISTAKE: Missing 'self' parameter
Forgetting 'self' in class method definitions: 
class Node:
    def print_val():  # ❌ CRASH! Missing self argument!
        print(val)

JS me functions automatic this context capture kar lete hain, par Python me class methods define karte waqt explicitly self pass karna compulsory hota hai.

💡 EASY WAY TO REMEMBER
  • Python __init__(self) = JS constructor()
  • Python self = JS this
  • Python None = JS null
