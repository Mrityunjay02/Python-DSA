1️⃣ Concept: The Python Interpreter & Numeric Bases

🟢 YE KYA HAI? (Definition)
Python terminal me jab hum >>> dekhte hain, ise REPL (Read-Eval-Print Loop) bolte hain. Yahan hum direct python statement likh kar check kar sakte hain.

🎨 REPL INTERACTIVE RUNS

# 1. Binary representation (0b or 0B prefix)
>>> print(0b10)
2
# Explain: 0b10 binary base-2 system me decimal equivalent '2' hota hai.

# 2. Hexadecimal representation (0x or 0X prefix)
>>> print(0X20)
32
# Explain: Hexadecimal 20 (base-16) decimal value '32' data hai.

🟢 TYPE CHECKING (int vs float)

🟢 VERIFYING OBJECT TYPE
Kisi bhi variable ka type check karne ke liye hum type() function ka use karte hain. 
>>> a = 10
>>> print(type(a))
<class 'int'>

>>> y = 2.8
>>> print(type(y))
<class 'float'>

2️⃣ Concept: Floats & Scientific Notations

🟢 SCIENTIFIC FLOATS (e or E notation)
Float value me standard decimal ke sath scientific representations e or E (10 ki power) use kar sakte hain. 
# 35 * 10^3
>>> x = 35e3
>>> print(x)
35000.0

# 12 * 10^4
>>> y = 12E4
>>> print(y)
120000.0
🔴 COMMON MISTAKE (Yahan dhyan rakhna!)
Dot write shortcut: 
>>> type(.4)
<class 'float'>

>>> type(2.)
<class 'float'>  # Evaluates to 2.0

Python me .4 likhne se ye automatic 0.4 ban jata hai, aur 2. likhne se ye 2.0 ban jata hai.

3️⃣ Concept: Booleans & Strings

# Booleans (Capitalized True/False)
>>> type(True)
<class 'bool'>

>>> type(False)
<class 'bool'>

# Strings (Single or Double Quotes)
>>> type("mrcet college")
<class 'str'>
💡 EASY WAY TO REMEMBER
  • Prefix 0b = Binary (base-2)
  • Prefix 0x = Hexadecimal (base-16)
  • Exponent e/E = Scientific power of 10
