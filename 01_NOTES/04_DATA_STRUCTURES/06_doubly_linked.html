🐍 Lesson 6: Doubly Linked Lists (Bidirectional Traversal)

Bhai, aaj hum Doubly Linked List (DLL) ke baare me seekhenge. Ye Singly Linked List ka ek upgraded version hai jisme hum linear sequence me dono directions (Aage aur Piche) me travel kar sakte hain.

1️⃣ Concept: Doubly Linked Node Structure

🟢 YE KYA HAI? (Definition)
Doubly Linked List me har node ke paas do memory pointers hote hain: next (jo agle node ko point karta hai) aur prev (jo pichle node ko point karta hai).

🖼️ DIAGRAM: DLL Node Connection Layout

DLLNode 1 DLLNode 2 +----------------------+ +----------------------+ | prev | val | next |<---->| prev | val | next |-----> None | None | 10 | | | | 20 | None | +----------------------+ +----------------------+
🟢 WHY USE IT?
  • Bidirectional Navigation: Hum list me forward aur backward dono directions me move kar sakte hain (Browser forward/backward logic).
  • Faster Deletions: Agar hamare paas kisi middle node ka address hai, to hum use constant time O(1) me delete kar sakte hain, kyunki pichle node ka address prev pointer me pehle se hi saved hota hai.

2️⃣ Code Implementation

class DLLNode:
    def __init__(self, val):
        self.val = val
        self.next = None
        self.prev = None  # Extra pointer for previous node connection

class DoublyLinkedList:
    def __init__(self):
        self.head = None

    # Insert at tail
    def insert(self, val):
        new_node = DLLNode(val)
        if not self.head:
            self.head = new_node
            return
            
        curr = self.head
        while curr.next:
            curr = curr.next
            
        # Link connections in both directions
        curr.next = new_node
        new_node.prev = curr  # DLL Specific link!

3️⃣ Avoid Common Pitfalls

🔴 COMMON MISTAKE: Updating Only One-Side Pointer
Missing the reverse link mapping: 
curr.next = new_node  # ❌ DLL me reverse pointer 'new_node.prev = curr' link karna compulsory hai!

Agar reverse link load nahi kiya to previous direction traverse karne par compiler data fetch nahi kar payega.

💡 EASY WAY TO REMEMBER
  • Singly Linked List = One-way road
  • Doubly Linked List = Two-way highway
