🐍 Lesson 1b: Types of Arrays (Static vs Dynamic & Dimensions)

Bhai, data structures me Arrays ko alag-alag aspects ke basis par categorize kiya jata hai. Chalo inko simple bhasha me samajhte hain.

1️⃣ Classification Based on Memory Allocation

🟢 STATIC ARRAY (Fixed Size)
Iski memory compile-time par hi declare ho jati hai aur iska size kabhi change nahi ho sakta.

Example: C/C++ me int arr[5];.

Drawback: Agar limit se zyada elements add karne hain, to dynamic resizing automatic nahi hoti. Memory waste ya shortage ho sakti hai.
🟢 DYNAMIC ARRAY (Resizable)
Iski size runtime par dynamic hoti hai. Jab array full ho jata hai, to ye automatically double size ka naya array memory me allocate karke purane elements ko copy kar leta hai.

Example: Python me standard List (arr = [1, 2, 3]), JS me standard Array, ya C++ me std::vector.

2️⃣ Classification Based on Dimensions (N-D Arrays)

1D Array (Linear): [ 10 | 20 | 30 ] (index 0, 1, 2) 2D Array (Matrix): [ 10 | 20 ] --> Row 0 [ 30 | 40 ] --> Row 1

3️⃣ Dimensional Details

  • One-Dimensional (1D) Array: Simple linear sequence of values. Single index se elements access hote hain. (Example: scores = [90, 85, 77])
  • Multi-Dimensional Array (2D, 3D, etc.):
    • 2D Array (Matrix): Grid system jisme Rows aur Columns hote hain. Elements access karne ke liye do indices ki zarurat hoti hai: matrix[row][col]. (Example: Chess board, image pixels).
    • 3D Array: Blocks of matrix (tensor). 3 indices use hote hain: cube[x][y][z]. (Example: 3D coordinates, RGB image channels).
