🐍 Lesson 1c: Array Rotation by K Steps (Optimized Reversal Trick)

Bhai, ye Array Rotation seekhne ke detailed notes hain. Isme humne Leetcode Medium category ki problem ko simple trick se crack kiya hai.

1️⃣ Concept: Rotating an Array

🟢 YE KYA HAI? (Definition)
Array rotation ka matlab hota hai elements ko cyclic way me shift karna. Agar hum bolte hain "Rotate Right by K=2 steps", to array ke aakhir ke 2 elements shuruat me aa jayenge.

🖼️ DIAGRAM: The 3-Step Reversal Algorithm (O(1) Space Hack!)

Initial Array: [ 1 | 2 | 3 | 4 | 5 ] (k = 2, Size n = 5) Step 1: Pure array ko reverse kar do [ 5 | 4 | 3 | 2 | 1 ] Step 2: Pehle K elements (index 0 se K-1) ko reverse karo [ 4 | 5 | 3 | 2 | 1 ] -- -- Step 3: Baaki bache elements (index K se n-1) ko reverse karo [ 4 | 5 | 1 | 2 | 3 ] ---> Target Output! -- -- --

2️⃣ Why We Use It?

🟢 COMPLEXITY ANALYSIS
  • Brute Force: Shift elements one-by-one K times. Time Complexity: O(k * n) - Extremely slow!
  • Extra Array: Copy elements to a temporary array. Space Complexity: O(n) - Consumes extra memory.
  • Reversal Trick: Time Complexity O(n) and Space Complexity O(1). Absolutely optimized!

3️⃣ Python Code Implementation

# Helper function to reverse a subarray range in-place
def reverse(arr, left, right):
    while left < right:
        arr[left], arr[right] = arr[right], arr[left]
        left += 1
        right -= 1

def rotate_array(arr, k):
    n = len(arr)
    # k if larger than n, modulo gets the remainder
    k = k % n 
    
    # Step 1: Reverse entire array
    reverse(arr, 0, n - 1)
    
    # Step 2: Reverse first k elements
    reverse(arr, 0, k - 1)
    
    # Step 3: Reverse remaining n-k elements
    reverse(arr, k, n - 1)
    
    return arr

4️⃣ Modulo Hack

💡 REDUCE REDUNDANCY: k = k % n
Agar array size 5 hai aur hum k = 5 rotation karenge to array wapas original ban jayega. Aise hi, k = 7 rotation is exactly identical to k = 2 rotation. Isiliye computation waste se bachne ke liye k = k % n kiya jata hai.
