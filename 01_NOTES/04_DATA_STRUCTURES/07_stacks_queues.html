🐍 Lesson 7: Stacks & Queues (LIFO vs FIFO & Deque optimization)

Bhai, aaj hum do super important linearly constrained data structures seekhenge: Stack aur Queue. Iska use tree traversals (BFS/DFS), backtracking, aur expression parsing me har jagah hota hai.

1️⃣ Concept: Stack (LIFO - Last In First Out)

🟢 YE KYA HAI? (Definition)
Stack me elements ka addition aur removal ek hi side (Top) se hota hai. Jo element sabse aakhir me daala gaya hai, wo sabse pehle niklega (LIFO).

🖼️ DIAGRAM: Stack Operations Flow

PUSH (Add at Top) POP (Remove from Top) | 30 | <-- Top [ 30 ] --> Out! | 20 | | 20 | <-- New Top | 10 | | 10 | +------+ +------+
stack = []

# 1. Push operation
stack.append(10)
stack.append(20)

# 2. Pop operation (Removes 20)
removed_val = stack.pop()

# 3. Peek (Check top element)
top_val = stack[-1]  # Python negative index

2️⃣ Concept: Queue (FIFO - First In First Out)

🟢 YE KYA HAI? (Definition)
Queue me insertion ek side (Rear/Tail) se hota hai aur deletion dusri side (Front/Head) se. Jo element pehle aaya hai, wo sabse pehle bahar niklega (FIFO).

🖼️ DIAGRAM: Queue Operations Flow

In (Enqueue) ────> [ 30 | 20 | 10 ] ────> Out (Dequeue) Rear Front
🔴 OPTIMIZATION: Why NOT use Python Lists for Queue?
The Shift Problem: Python list me agar hum start se element delete karein (list.pop(0)), to baaki sabhi elements ko ek-ek position left shift karna padta hai. Iski time complexity O(N) ho jati hai jo bohot slow hai.

Solution (collections.deque): Python me queue ke liye hum collections module se deque (double-ended queue) use karte hain. Isme start se delete karna (popleft()) O(1) time complexity me efficient ho jata hai. 
from collections import deque

# 1. Deque initialize karna
queue = deque()

# 2. Enqueue (Insert at Rear)
queue.append(10)
queue.append(20)

# 3. Dequeue (Remove from Front in O(1) time)
first_out = queue.popleft()  # returns 10
