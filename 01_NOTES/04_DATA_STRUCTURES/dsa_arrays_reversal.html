1️⃣ Concept: Two-Pointer Approach

🟢 YE KYA HAI? (Definition)
Kisi array ko bina extra memory space use kiye (In-place) ulta karne ka best tarika hai Two-Pointer Approach. Isme hum do markers (indices) ka use karte hain: ek shuruat me (Left) aur ek aakhir me (Right).

🖼️ DIAGRAM: Two-Pointer Swap Flow

Step 1: Start (Left at index 0, Right at index 4) L R [ 10 | 20 | 30 | 40 | 50 ] ---> Swap 10 and 50 0 1 2 3 4 Step 2: Move pointers (Left + 1, Right - 1) L R [ 50 | 20 | 30 | 40 | 10 ] ---> Swap 20 and 40 0 1 2 3 4 Step 3: Meet at center (Left = Right = 2) -> STOP! L/R [ 50 | 40 | 30 | 20 | 10 ]

2️⃣ Why We Use It?

🟢 ADVANTAGES
  • Space Complexity O(1): Kyunki hum koi naya duplicate array nahi bana rahe hain, bas usi array me values swap kar rahe hain (In-place).
  • Time Complexity O(n): Pure array ko sirf ek baar scan karne me half elements ko swap kiya, isiliye runtime single loop me khatam ho jata hai.

3️⃣ Code Implementation

def reverse_array(arr):
    # 1. Pointers setup kiya
    left = 0
    right = len(arr) - 1

    # 2. Loop tab tak chalega jab tak dono pointers cross nahi karte
    while left < right:
        # 3. Pythonic Swap (bina third temp variable ke direct swap)
        arr[left], arr[right] = arr[right], arr[left]
        
        # 4. Pointers ko pass laaye
        left += 1
        right -= 1
    
    return arr

4️⃣ Avoid Common Pitfalls

🔴 COMMON MISTAKE (Yahan phasoge!)
Loop Condition galat dena: 
while left <= right:  # ❌ Redundant operation!

Agar loop me <= laga diya to center wala element khud se swap hoga, jo ki completely unnecessary operation hai.
