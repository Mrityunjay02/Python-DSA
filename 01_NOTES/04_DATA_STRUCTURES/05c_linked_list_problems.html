1️⃣ Pattern 1: Find Middle Node in 1-Pass

🟢 YE KYA HAI? (Definition)
Ek pass (loop) mein bina list ki length count kiye middle node dhundna. Ise Fast & Slow Pointer technique se solve karte hain.

🖼️ DIAGRAM: Fast & Slow Pointer Flow

Odd length: [ 10 ] ──> [ 20 ] ──> [ 30 ] ──> [ 40 ] ──> [ 50 ] ──> None Step 1: slow/fast Step 2: slow fast Step 3: slow fast (End!) Middle = 30

🔵 CODE EXPLANATION (Middle Node)

def find_middle(head):
    slow = head
    fast = head
    
    # fast 2-steps chalega, slow 1-step
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        
    return slow  # slow is exact middle!

2️⃣ Pattern 2: Merge Two Sorted Linked Lists

🟢 YE KYA HAI? (Definition)
Do already sorted linked lists ko merge karke ek single sorted linked list banana, bina extra node create kiye (in-place pointer stitching).

🖼️ DIAGRAM: Dummy Node Stitching

List 1: [ 10 ] ──> [ 30 ] ──> [ 50 ] List 2: [ 20 ] ──> [ 40 ] Dummy: [ 0 ] ──> [ 10 ] ──> [ 20 ] ──> [ 30 ] ──> [ 40 ] ──> [ 50 ] ──> None

🔵 CODE EXPLANATION (Merge Two Sorted Lists)

def merge_sorted_lists(l1, l2):
    # Dummy node gives a clean start pointer
    dummy = Node(0)
    curr = dummy
    
    while l1 and l2:
        if l1.val <= l2.val:
            curr.next = l1
            l1 = l1.next
        else:
            curr.next = l2
            l2 = l2.next
        curr = curr.next
        
    # Attach the remaining chain
    curr.next = l1 if l1 else l2
    
    return dummy.next
💡 EASY WAY TO REMEMBER
  • Middle Find = Slow walks 1 step, Fast runs 2 steps.
  • Merge Sorted = Dummy node banao, chhota element link karo, pointer aage badhao.
