1️⃣ Concept: String Immutability

🟢 YE KYA HAI? (Definition)
Python me strings Immutable (un-changeable) hote hain. Ek baar string memory me ban gayi, to uske kisi character ko change nahi kiya ja sakta.
🔴 COMMON MISTAKE (Yahan code crash hoga!)
s = "hello"
s[0] = "y"  # ❌ CRASH! TypeError: 'str' object does not support item assignment

JS me ye silent fail hota hai (strict mode ke bina), par Python me ye error dekar program ko crash kar deta hai.

💡 EASY WAY TO REMEMBER (String Swap Trick)
  • String to List: char_list = list(s) (Ab ye mutable hai).
  • Do swap operations: char_list[left], char_list[right] = char_list[right], char_list[left]
  • List to String: s = "".join(char_list) (Wapas string ban gayi).

2️⃣ Concept: Palindrome & Anagram Check

1. Palindrome Check (Two-Pointer)

Agar kisi string ko seedha ya ulta padhne par same word bane (e.g., "radar", "madam"). 
def is_palindrome(s):
    left = 0
    right = len(s) - 1
    while left < right:
        if s[left] != s[right]:
            return False
        left += 1
        right -= 1
    return True

2. Anagram Check (Sorting Method)

Do strings anagram hain agar unke letters ka count exactly same ho (e.g., "listen" aur "silent"). 
# Sorting Method - Time: O(n log n)
def is_anagram(s1, s2):
    return sorted(s1) == sorted(s2)
