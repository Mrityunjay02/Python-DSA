1️⃣ Concept: Reverse a Linked List (Iterative)

🟢 YE KYA HAI? (Definition)
Linked List ko reverse karne ka matlab hai ki har node ka pointer agle node ki jagah pichle node ko point karne lage. Ise hum bina naya space allocate kiye (in-place) 3 pointers (prev, curr, next_node) ki help se karte hain.

🖼️ DIAGRAM: Linked List Reversal Step

Current State: prev curr next_node [ None ] [ 10 | next ] ------> [ 20 | next ] ------> [ 30 ] | v (link change) [ 10 | next ] ──────> prev (None)

🔵 CODE EXPLANATION (Iterative Reversal)

def reverse_list(head):
    prev = None
    curr = head
    
    while curr:
        # 1. Save agle node ka reference
        next_node = curr.next
        
        # 2. Pointer direction reverse karo
        curr.next = prev
        
        # 3. Pointers ko step aage badhao
        prev = curr
        curr = next_node
        
    return prev  # prev is the new head

2️⃣ Concept: Loop / Cycle Detection (Floyd's Cycle Algorithm)

🟢 YE KYA HAI? (Definition)
Agar list ka last node None ko point karne ki jagah piche kisi node se connect ho jaye, to use loop bolte hain. Ise track karne ke liye hum Tortoise & Hare algorithm use karte hain.

🖼️ DIAGRAM: Tortoise and Hare Cycle

[ 10 ] ──> [ 20 ] ──> [ 30 ] ^ | | v └──────── [ 40 ] (Loop back to 20!)
🟢 FLOYD'S LOGIC
slow pointer ek step chalega (slow = slow.next), aur fast pointer do steps chalega (fast = fast.next.next). Agar cycle hai, to dono pointers eventually aapas me meet point par milenge! Space Complexity O(1) me check ho jata hai.

🔵 CODE EXPLANATION (Cycle Detection)

def has_cycle(head):
    slow = head
    fast = head
    
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        
        if slow == fast:  # Meet point reached
            return True
            
    return False  # Fast reaches None (No Loop)
💡 EASY WAY TO REMEMBER
  • Reversal Trick = next_node = curr.next, curr.next = prev, shift pointers.
  • Cycle Detection = Slow walks, Fast runs. If loop, they will meet!
