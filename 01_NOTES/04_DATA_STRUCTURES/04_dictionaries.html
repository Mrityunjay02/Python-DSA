🐍 Lesson 3: Python Dictionaries (Hash Maps) Under the Hood

Bhai, aaj hum Python ka sabse powerhouse data structure seekhenge: Dictionaries (dict). Iska use DSA me frequency counting, hashing, aur lookup optimization me har jagah hota hai.

1️⃣ Concept: Dictionary & Hash Maps

🟢 YE KYA HAI? (Definition)
Python me Key-Value pairs store karne ke liye Dictionary use hoti hai. Ye unique keys ko specific values se map karti hai aur internal hash table dynamic structure ka use karti hai.

🖼️ DIAGRAM: Hash Map Layout in Memory

Key (String/Int) ----> [ Hash Function ] ----> Bucket Index ----> Value "name" ----> (Calculates) ----> [3] ----> "Amit" "age" ----> (Calculates) ----> [7] ----> 25
🟢 WHY USE IT?
  • Constant Time Lookup O(1): Kyunki keys directly math computation (Hash) se specific memory bucket me map hoti hain, isiliye search time hamesha O(1) hota hai.
  • Frequency Counting: DSA problems me character occurrence count karne ke liye best option hai.

2️⃣ Code Implementation

# 1. Dictionary initialization
user = {"name": "Amit", "age": 25}

# 2. Key-value insert/update
user["city"] = "Delhi"

# 3. Frequency Counter Pattern (Very useful for Anagrams & Sliding Window!)
s = "apple"
freq = {}
for char in s:
    # .get(char, 0) checks if char exists. If not, returns default 0.
    freq[char] = freq.get(char, 0) + 1

print(freq)  # Output: {'a': 1, 'p': 2, 'l': 1, 'e': 1}

3️⃣ Avoid Common Pitfalls

🔴 COMMON MISTAKE: KeyErrors (Crash!)
Direct Key Access on non-existent keys: 
user = {"name": "Amit"}
print(user["age"])  # ❌ CRASH! KeyError: 'age'

JS me non-existent keys undefined return karti hain, par Python strict hai aur KeyError throw karta hai. Hamesha check karein: if "age" in user: ya use karein .get() method.
