🐍 Lesson 5: Singly Linked List Implementation (CRUD Operations)

Bhai, aaj hum seekhenge ki kaise ek wrapper class banakar hum standard Singly Linked List implement karte hain aur usme items insert, delete, aur search karte hain.

1️⃣ Concept: Singly Linked List Wrapper

🟢 YE KYA HAI? (Definition)
Abhi tak humne sirf simple Node objects ko aapas me connect kiya hua dekha tha. Lekin pure chain ko handle karne ke liye hum ek wrapper class banate hain jise LinkedList bolte hain. Ye list ke starting node (head) ko track karti hai.

🖼️ DIAGRAM: Delete Operation Flow

Target: Delete node with value 20 Before Delete: [ 10 | next ] ------> [ 20 | next ] ------> [ 30 | next ] ------> None (curr) (temp) After Pointer Adjustment (Bypass 20): [ 10 | next ] ────────────────────────────> [ 30 | next ] ------> None (curr.next = curr.next.next)
🟢 WHY USE IT?
  • Array me elements ko start ya middle se delete karne me shifting karni padti hai O(N).
  • Linked List me hum bina elements ko shift kiye, sirf address variables adjust karke dynamic insertion aur deletion O(1) perform kar sakte hain.

2️⃣ Code Implementation

class Node:
    def __init__(self, val):
        self.val = val
        self.next = None

class LinkedList:
    def __init__(self):
        self.head = None  # Initially list is empty

    # 1. Insert at end (Tail)
    def insert(self, val):
        new_node = Node(val)
        if not self.head:
            self.head = new_node
            return
        
        curr = self.head
        while curr.next:  # Traverse to last element
            curr = curr.next
        curr.next = new_node  # Link new node at the end

    # 2. Delete by Value
    def delete(self, val):
        if not self.head:
            return
        
        # Case 1: Head node contains the target value
        if self.head.val == val:
            self.head = self.head.next
            return
            
        # Case 2: Traverse to find target element
        curr = self.head
        while curr.next:
            if curr.next.val == val:
                # Bypass target node
                curr.next = curr.next.next
                return
            curr = curr.next

    # 3. Search
    def search(self, val):
        curr = self.head
        while curr:
            if curr.val == val:
                return True
            curr = curr.next
        return False

3️⃣ Avoid Common Pitfalls

🔴 COMMON MISTAKE: Losing Head Pointer
Traversing directly modifying self.head: 
while self.head:
    self.head = self.head.next  # ❌ CRASH/BUG! Head pointer is lost forever!

Traversing ke liye hamesha ek duplicate iterator curr = self.head banayein, direct self.head ko loop me modify na karein.
